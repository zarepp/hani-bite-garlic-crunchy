# Hani Bite Garlic Crunchy

React single-page site built with Vite.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Deploy to GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the site when changes are pushed to `main`.
In the repository settings, set **Pages > Build and deployment > Source** to **GitHub Actions**.

The project site URL is <https://zarepp.github.io/hani-bite-garlic-crunchy/>.
